## Окно приложения

После разблокировки Mac проведена ручная проверка на новой отдельной базе `blog_platform_kr2_gui_verify_20261010`:

- Автор: пустая форма показывает ошибку и остаётся открытой; создание, поиск по email, изменение имени и роли через ComboBox сохраняются в БД.

- Повторный адрес публикации отклоняется, форма не закрывается; после исправления адреса сохранение проходит.
- Переходы `DRAFT → REVIEW → PUBLISHED`; дата публикации появляется на шаге `PUBLISHED`.
- Поиск по имени автора вместе с фильтрами статуса и автора даёт один ожидаемый результат.
- Клики по заголовку столбца меняют сортировку по заголовку на прямую и обратную; начальная сортировка по дате — от новых к старым.

- Комментарий: выбор публикации и автора из ComboBox, создание, изменение текста и модерация в `APPROVED`.
- Удаление запрашивает подтверждение; отмена сохраняет запись. Само удаление и каскад проверены интеграционными тестами, а не вручную на пользовательской базе.
